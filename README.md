# Taichi2027｜楊家老架式太極拳數位練習平台

以網頁方式整理**楊家老架式太極拳 108 式**的四節口令，提供方便查閱、聆聽與逐段練習的互動介面，並探索可旋轉視角的 3D 動作教學。

## 專案介紹

Taichi2027 旨在將傳統太極拳的口傳教學整理成可搜尋、可朗讀、可反覆操作的數位教材。現階段以**四節完整口令**為核心，逐步增加動作視覺化、語音提示及多視角觀察功能。

### 主要功能

- **四節口令查閱**：依第一節至第四節瀏覽，也可一次顯示全部內容。
- **招式與口令搜尋**：快速找到指定名稱或動作提示。
- **逐段練習**：上一段／下一段切換，適合個人練習。
- **中文語音朗讀**：使用裝置內建的中文語音合成，可調整朗讀速度。
- **完成進度紀錄**：在目前瀏覽器儲存練習完成狀態。
- **手機與桌面適用**：響應式版面，支援列印。
- **3D 起勢試作**：可旋轉、縮放視角，切換正面／側面／背面，控制示意動作進度，並匯出 HD 靜態畫格。

## 3D 教學試作說明

第一式「起勢」目前是**互動 3D 技術原型**，並非根據師父影片完成的動作捕捉或精準復原。其手型、身法、重心與動作時間軸仍待校準。

- 目前語音為瀏覽器 TTS，**不是真實老師父配音**。
- 目前可匯出 1920 × 1080 靜態 PNG 畫格，**尚未提供 MJPEG 動作影片**。
- 3D 原型中的動作順序與姿態僅供技術展示，**不應作為標準拳架的唯一依據**。
- 主站以提供的原始口令分段為「練習單元」，**不代表已重新核定傳統 108 式編號**。

## 技術

主站使用 HTML、CSS 與原生 JavaScript；3D 原型使用 Three.js 與 OrbitControls。網站由 GitHub Pages 靜態部署，不需要額外後端服務。語音功能依賴瀏覽器 Web Speech API，實際可用語音因裝置與瀏覽器而異。
